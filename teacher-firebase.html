⚙️ Cấu Hình Firebase

Nhập thông tin Firebase để kết nối database (chỉ cần làm 1 lần)

📖 Hướng dẫn tạo Firebase:

  1. Truy cập: Firebase Console
  2. Tạo project mới
  3. Vào "Realtime Database" > Create Database > Start in test mode
  4. Vào Project Settings > General > Scroll xuống "Your apps"
  5. Copy Firebase configuration và dán vào form trên

Đăng Nhập Giáo Viên

Tên mặc định: admin
